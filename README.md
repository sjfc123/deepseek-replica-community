# DeepSaga

DeepSaga 是基于上游 Android WebView 容器与对话前端改造的本地角色扮演、普通对话客户端。仓库只提供源代码、构建配置、测试脚本和说明文档；不提供预编译 APK、在线服务、账号系统、代理接口或代打包服务。

## 3. 核心功能

### 3.1 对话与接口

- 支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 与自定义兼容网关。
- 支持本地兼容端点，包括 Ollama、LM Studio、vLLM、LocalAI 等实现 OpenAI 兼容协议的服务。
- 可配置接口地址、模型名、API Key、自定义请求头、采样参数、温度、Top P、最大输出 Token。
- 支持流式回复、消息重生成、编辑用户消息、编辑模型回复、删除单条消息、消息版本保留。
- 支持图片、文件、PDF 等附件；附件能否发送由所选网关的文件能力决定。
- 深度思考开关、智能搜索开关和安全审核字段是否生效，取决于网关是否接受对应请求字段。

### 3.2 会话与本地数据

- 会话支持新建、重命名、置顶、分组、归档、批量移动、复制、导出和删除。
- 多选支持全选、取消全选与首尾范围选择；桌面端可使用 `Shift` 选择连续区间。
- 支持从任意消息创建分支；分支继承分叉点之前的上下文、记忆和场景，不继承分叉点之后的内容。
- 会话、分支、消息版本、草稿、附件引用、角色卡、世界书、场景、记忆、设置和备份元数据保存在本机。
- 支持历史会话 ZIP、单会话包、设定存档和记忆归档导入导出；导入校验 ZIP 结构、条目 CRC、会话 JSON、消息分支和完整性摘要。
- 自动备份先写临时文件，核对大小并校验 ZIP 后发布；默认保留最近 5 份完整备份。

### 3.3 角色扮演

- 全局同一时间只启用一张角色卡；会话可绑定独立角色，绑定优先于全局开关。
- 人物层为角色卡、基础档案、轻量身份行三选一，不叠加冲突身份。
- 基础档案包含基本信息、身体与生活、性格与边界、剧情与表达四类字段。
- 角色卡包含固定参数、生活细节、性格边界、题材玩法、关系、经历、情景、目标、说话方式、口癖、秘密、补充设定、开场参考、对白示例和卡内指令。
- 支持 Character Card V2/V3、TavernAI、PNG chara 导入。
- 世界书支持关键词或正则命中、常驻条目、按角色绑定、单轮预算、最近发言或整段历史扫描、避触词和可信度分层。
- 场景覆盖时间、地点、天气、穿着、心情、关系阶段、氛围、在场人物、目标、冲突悬念和关键物件。
- 官方助手人格是独立开关；开启时不叠入手写系统提示词、自定义预设或基础扮演。内置基础扮演只补空白新会话；官方人格关闭且没有其它身份来源时，内置兜底人设接管，已有历史由消息上下文自然延续。显式绑定到选中会话的自定义角色扮演预设，按所选范围作为同级身份来源生效。
- 从已绑定系统提示词或自定义预设的会话新建对话、复制分支时，新会话自动继承同一份会话绑定；旧版全局继承记录保持全局，不强行展开成显式数组。

### 3.4 长期记忆

- 记忆分为角色记忆与普通记忆两个独立池，分别限制卡片数量和字符预算。
- 角色记忆分为完整回合、重要场景、关键事实三层。
- 普通记忆分为对话、代码、用户原话、AI 原话四类，按关键词检索。
- 记忆按会话和分支隔离；新建会话不继承旧会话记忆，分支继承分叉点之前的卡片。
- 支持手动补卡、置顶、编辑、删除、跳转、时间锚点召回、分类筛选和分类导入导出。
- 记忆进入模型上下文，不是数据库事实；模型可能忽略、误用、重复或混淆记忆内容。

### 3.5 个性化与展示

- 支持用户头像、用户名、角色头像、角色名、头像大小、头像形状、主题色、气泡样式、布局、字体大小和消息间距。
- 个性化设置只影响本机显示，不进入请求，不随设定存档导出。
- 主页支持自定义 LOGO、头像和标题；主页台词保存在本机台词池中。
- 支持朗读音色试听；试听会产生一次 TTS 请求。
- 支持深浅色主题、设置搜索、折叠分区和移动端布局。

### 3.6 用量、余额与诊断

- Token 统计读取上游返回的 `usage`，记录输入、输出、缓存命中、未命中、思考 Token 与安全 Token；上游缺失字段按缺省处理，不本地补造数值。
- 余额优先请求官方 `/user/balance`；网关不支持或网络失败时进入降级态。应用不按本地费率推算账单金额。
- 缓存样本只保存指纹、长度、开关、计数与 usage，不保存 system 正文、聊天正文或 API Key。
- 诊断日志覆盖提示词分层、缓存趋势、渲染溢出、滚动锁、动画数量、事件循环、帧间隔、内存、存储配额、网络和重复消息等项目。
- 诊断日志可能包含请求元信息、角色名和来源链接；对外提供前必须检查是否包含 Key、地址或聊天内容。

### 3.7 语音链路

- 支持 VAD 断句、ASR 转写、流式 TTS 和播放中插话打断。
- 无活动会话时可直接开麦；首条转写会创建会话并生成标题。
- WebView 采集被系统拦截时，尝试切换原生 `AudioRecord`；原生通道中断后最多重建两次。
- 语音链路依赖 WebView、麦克风权限、音频焦点和 Android 版本；权限拒绝、后台限制或录音通道占用会导致失败。

## 4. 1.0.0 正式版变更

### 4.1 新增功能

- **自定义角色扮演预设提示词**：可填写自定义身份与扮演规则，并按历史会话选择生效范围；预设与手写系统提示词处于同级身份来源。
- **双侧会话范围互斥**：系统提示词已选的会话，在自定义预设选择器内置灰；自定义预设已选的会话，在系统提示词选择器内同样置灰，避免同一对话同时绑定两段身份。
- **官方人格同级互斥**：填写手写系统提示词、启用自定义预设或开启基础扮演时，官方助手人格自动关闭；重新开启官方人格会关闭这三个同级身份来源。文本与会话绑定保留在本机，不会被清空。
- **手写身份优先**：在系统提示词或自定义预设中写明 DeepSeek、GPT、Claude、千问、豆包、Kimi、Gemini、Grok 等模型或产品身份时，按所写身份生效；内部角色锁定不覆盖用户明确写出的身份。
- **元叙述压制范围**：该开关只作用于内置兜底人格；角色卡、基础档案、基础扮演、手写系统提示词和自定义预设不再叠加同一套元叙述约束。

## 5. 构建、安装与迁移

### 5.1 前端构建

```bash
pnpm install
pnpm type
pnpm lint
pnpm build
```

构建产物输出到 `dist/`。

### 5.2 Android 构建

```bash
cd android
./gradlew assembleRelease
```

工程基线为 Gradle 9.7.1、AGP 9.4.0、minSdk 29、targetSdk 36；`compileSdk` 跟随本机已安装平台。构建者必须自行生成并保管签名密钥；签名文件、Keystore 密码和发布凭据禁止提交仓库。

### 5.3 旧版数据迁移

`0.9.0` 使用独立包名，Android 将其与旧版 `io.github.lijiahua1024.dsreplica` 视为两款应用。两版可并存安装，但不共享应用数据。

1. 在旧版执行“导出所有历史对话”。
2. 在 DeepSaga 执行“导入历史对话”，选择旧版导出的 ZIP。
3. 重新填写 API Key；备份不包含 API Key。
4. 检查角色卡、世界书、场景与记忆是否完整。旧格式字段缺失或无法定位的条目会被排除并计数，不保证全部恢复。

内部 `replica:` 存储键保持不变，用于兼容既有数据。

## 6. 数据与隐私

- 无账号体系，无中转服务器，无开发者数据收集。
- API Key 由使用者填写，Android 侧通过 Keystore 加密存储。

- 请求只发往使用者配置的接口地址；网关、服务商和网络环境的记录方式不在本仓库控制范围内。
- 导出备份不包含 API Key，但可能包含聊天记录、角色卡、设定和图片；对外发送前必须检查内容。
- 卸载应用、清理应用数据或设备损坏会删除本地数据，使用者必须自行备份。

## 8. 已知技术边界

- **设备与 WebView**：未覆盖全部厂商 ROM、Android 版本、WebView 内核、折叠屏、分屏、悬浮窗和低内存设备。白屏、闪退、权限拒绝和录音通道差异必须在目标设备复现后处理。
- **网关差异**：不同网关对图片、工具调用、搜索、推理参数、缓存字段和自定义协议支持不一致。部分 400、空回复、余额不可用或计费异常来自上游，前端无法单方面修复。
- **模型输出**：角色一致性、称呼、语气、记忆引用、功能推荐和长文结构取决于模型能力、采样参数、上下文长度、角色卡质量和历史完整性。现有提示词约束只降低跳脱概率，不保证模型一定遵守。
- **规则清洗**：思考展示层按固定规则切除残留计划句和态度话术，不是语义理解。新措辞可能漏过，旧词也可能误伤人物原话。
- **长上下文**：超长会话、大量记忆卡、超大角色卡和世界书会触发压缩、截断、渲染卡顿或内存压力；现有配额是保护机制，不是无限容量承诺。
- **历史导入**：历史版本、第三方修改版和手工编辑包可能存在字段缺失、ID 冲突或格式不一致。无完整性摘要的旧备份只能校验结构与分支，无法发现字段合法但内容被截断或改写的情况。
- **缓存命中**：命中由上游按完整前缀判断；切换模型、角色卡、分支、开关状态、编辑历史、触发压缩或提醒变化都会改变前缀。诊断只定位可能断点，不保证命中率。
- **提示词绑定**：当前实现为单条手写系统提示词绑定一组会话；多段独立提示词分别绑定不同会话的模型不在本轮范围内。
- **回归范围**：仓库内回归脚本覆盖提示词、检索意图、角色、故事、备份、数据、附件、记忆、分组、建议、缓存、余额与主题令牌等链路；脚本通过不等于所有真实设备、模型和对话场景无缺陷。
